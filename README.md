# 🌤️ Weather Report

A full-stack weather application that provides current weather information and a 5-day forecast for different cities.

## 🚀 Features

- 🔍 Search weather by city
- 🌡️ Current temperature and weather conditions
- 📅 5-day weather forecast
- 📍 City-based weather information
- 💻 Responsive and user-friendly interface
- 🔐 API key protected using environment variables

## 🛠️ Technologies Used

### Frontend
- React
- Vite
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- OpenWeather API
